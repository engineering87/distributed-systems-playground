        Language quick reference
        
    
          
    A program contains interfaces and algorithms. An algorithm implements one interface and uses others: Net (network) and Rounds (synchronous rounds) are provided by the simulator; the rest you write yourself, and they are wired together automatically.
    

    upon event ⟨instance, Event | pattern⟩ where condition do … end
upon condition expression do … end
upon exists x in S where condition do … end
trigger ⟨instance, Event | arg1, arg2⟩
forall q in neighbors where q ≠ p do … end
if … then … elif … then … else … end
starttimer(t, 100ms)   canceltimer(t)
⟨timer, Timeout | t⟩   assert cond, "msg"   log x
    
          
    Indications go up, requests go down. Undeclared all-caps words (HEARTBEAT) are atoms. In patterns, a new name captures the value; an atom or a known name must match.
    
          
    Built-ins: self, Π, N, neighbors, round, now(), DELTA PHI RHO (only when known in the assumed model), min max choose size keys values map() random(a,b) append toset str abs. Tuples are 0-indexed; #S is the cardinality. Durations (50ms) are numbers in microseconds.
    
          
    ASCII equivalents: < > for ⟨ ⟩, union inter minus in notin subseteq, != <= >=, and or not, Procs for Π, {} for ∅. Inside an ASCII trigger, wrap comparisons in parentheses.
    
        
    
      
    
    
    

    
    
      
    
      
    
      
    
        
    
          Assumed model what the algorithm believes
          
          
    
            
            
            
          
    
          
    Write unknown for a bound that exists but the algorithm does not know. DELTA: maximum delay; PHI: maximum step duration; RHO: maximum clock drift.
    
          
    
            
            
            
    Each process opens round r when its own clock reads r·(DELTA+PHI).
    
          
    
          
        
    
        
    
          Actual model what the system really does
          
          
          
    
          
    
            
            
            
            
            
            
          
    
          
          
    
            
            
            
            
          
    
          
    Distributions: const(d) uniform(a, b) exp(mean) normal(μ, σ) lognormal(μ, σ) (μ, σ in log ms) pareto(xm, α) empirical(a, b, …). Unitless numbers are ms. Messages sent before GST still arrive by GST + bound.
    
          
        
    
      
    
    
    

    
    
      
      
    One event per line: TIME NODE Event | arguments, where * means every process. Examples: 0ms 1 Broadcast | "hello", 0ms * Propose | random(1, 9). Events must be requests of the main algorithm. You can also select a process during playback and inject an event at the current time.
    
      
    Faults
    
      
      
      
      
        
        
        
        
        
        
        
        
        
      
      
      
      Processes not listed in a partition form one more group together, so 3 alone isolates p3. Leave Until empty for a permanent failure. A recovered process restarts with its volatile state reset: variables declared stable keep their value, and each module receives Recovery if it handles it, Init otherwise. During playback you can also select a process or a link and inject a crash, recovery, isolation or link failure at the current time.
